## 🔭 What This Actually Is

Picture a lighthouse keeper who also happens to be an accountant. That is roughly the energy of this repository. The **Elden Ring Companion Suite** is a modular desktop application that observes, records, and visualizes game-state information in a way that respects both your time and your hardware. It sits quietly in the corner of your screen like a well-behaved spirit ash, offering insight without shouting.

The suite is built around a lightweight observation layer, a responsive front end, and a plugin-friendly backend. Nothing here overwrites your save. Nothing here silently rewrites memory in ways you can’t undo. Everything is logged, reversible, and — crucially — **your choice**.

If you’ve ever wondered *why* a particular weapon feels better at a specific rune level, or *how* your flask economy drifts across a long session, this is the ledger that finally answers those questions.

---

## 🗺️ A Short Field History

The project started, as many do, as a weekend experiment: a tiny script with a grand ambition. Over time, contributors added visual dashboards, localization files, and a plugin system. The original concept — a **simple elden ring trainer** — evolved into something closer to an analytics companion. We kept the spirit of the original: direct, lightweight, and unpretentious. We simply gave it a larger library and a nicer lamp.

Today the suite supports multiple display modes, community translations, and a documented extension API. It is the kind of repository that grows on you the way a good talisman does — slowly, then all at once.

## ✨ Feature Constellation

Every feature below is designed to answer a real question a player might ask at 2 AM while staring at a fog wall.

### 🎛️ Live Attribute Observatory

A real-time view of your character’s core statistics, with deltas, rolling trends, and threshold markers. Watch how a single point of Endurance reshapes your entire stamina curve. Think of it as a telescope for spreadsheets — you don’t just see the number, you see the shape behind it.

- Historical tracking across sessions
- Threshold alerts for soft caps
- Side-by-side comparison between saved builds
- Export to plain-text ledgers for external notes

### 💠 Rune Economy Dashboard

Track how runes enter and leave your life. Sort by source, region, and time. Identify which areas are quietly profitable and which are quietly draining.

- Per-region rune yield estimates
- Session-based gain/loss timelines
- Optional budget mode with alerts
- CSV-style plain output for your own analysis

### 🧪 Crafting & Flask Laboratory

A dedicated workspace for consumables, craftables, and flask allocations. Experiment with hypothetical distributions without touching your live inventory.

- Flask allocation simulator
- Crafting ingredient requirement trees
- Substitution suggestions for rare materials
- Persistent “what-if” scenarios

### 🗡️ Damage & Scaling Sandbox

A math playground that isolates one variable at a time. Want to know how a weapon behaves at a specific stat spread? The sandbox answers without requiring a respec.

- Affinity and scaling exploration
- Buff stacking visualization
- Breakpoint discovery for status effects
- Comparison table generator

### 📚 Lore Vault & Item Codex

A searchable codex of items, locations, and NPCs, cross-linked by region and questline. It is part encyclopedia, part corkboard with red string.

- Fuzzy search across items and NPCs
- Questline dependency graph
- Region-based filtering
- Offline-friendly data packs

### 🧭 Route Planner & Grace Weaving

Plot efficient routes between points of interest. Useful for challenge runs, collection runs, or simply wandering with intention.

- Multi-stop route optimization
- Grace-based checkpoint lists
- Estimated travel time ranges
- Shareable route files

### 🌐 Multilingual Support

The interface speaks many languages, and more arrive with every release. Community translators drive this entirely — we simply provide the plumbing.

- Locale files split by module
- Right-to-left layout support
- Community translation review pipeline
- Fallback language chains

### 📱 Responsive Interface

From ultrawide monitors to compact laptop screens, the layout reshapes itself gracefully. No pixel is wasted, no panel is orphaned.

- Adaptive panel docking
- Compact and expanded view modes
- Adjustable font scaling
- Keyboard-first navigation

### 🛎️ Round-the-Clock Assistance

A support channel that never sleeps, staffed by maintainers and veteran contributors. Questions get answers; bug reports get triaged; ideas get discussed like adults at a campfire.

- Documented support hours in local time
- Issue templates tuned for clarity
- Community chat bridges
- Escalation path for critical regressions

### 🧩 Plugin Architecture

Extend the suite with your own modules. The API is documented, versioned, and mercifully boring — the best compliment a plugin system can receive.

- Sandboxed plugin runtime
- Capability-based permissions
- Hot-reload during development
- Example plugins shipped in-repo

### 🔒 Local-First Privacy Model

Your data stays on your machine by default. No telemetry, no silent uploads, no phone-home curiosity.

- Opt-in sync only
- Encrypted local storage
- Clear data retention controls
- Audit log of every read/write

### 🎨 Theme Weaver

Build and share color themes. Choose from presets inspired by regions, weathers, and moods — or craft your own palette from scratch.

- Live theme preview
- Community theme gallery
- Accessibility contrast checks
- Export/import theme bundles

## 🧠 Design Philosophy

We believe tools should be **transparent**, **reversible**, and **respectful**. Every feature is judged against three questions:

1. Does it clarify something the player couldn’t otherwise see?
2. Can it be undone without consequence?
3. Does it still work when the internet is gone?

If a feature fails any of those, it doesn’t ship. This is why the suite leans local-first, why every action is logged, and why we stubbornly refuse to add anything that makes the game play itself.

## 🚀 Getting the Ledger Running

Setup is deliberately gentle. There is no arcane ritual, no terminal incantation, no dependency labyrinth. You retrieve the current release bundle, unpack it into a folder of your choosing, and launch the main executable. On first run, the suite walks you through a short onboarding: pick a language, pick a theme, and choose which modules to enable.

If you prefer a portable setup, the suite supports a self-contained mode where all configuration lives beside the executable. Perfect for USB drives and shared machines.

For advanced users, a headless mode exists for scripted workflows and CI-style batch analysis.

## ⚙️ Configuration Profiles

## 🔌 Extending the Suite

Plugins live in a dedicated folder and are loaded at startup. Each plugin declares its capabilities, and the runtime enforces those boundaries strictly.

A minimal plugin might add a new dashboard panel. A larger one might integrate an external note-taking system. The API surface is documented, versioned, and tested against every release.

We encourage plugins that **add clarity** rather than **remove challenge**. If your plugin plays the game for the user, it belongs in a different project.

## 🌍 Community & Localization Pipeline

Translations flow through a review pipeline that respects both speed and quality. Translators submit locale files, reviewers verify context, and maintainers merge. The result is an interface that feels native in dozens of languages.

We are always seeking new locales, especially for underrepresented languages. The pipeline is friendly to first-time contributors — you do not need to be a programmer to help.

## 🧯 Troubleshooting Cauldron

Common issues and their remedies live in a dedicated guide. In brief:

- **Overlay not appearing** — verify your display mode and window focus settings.
- **High CPU usage** — disable modules you aren’t actively using.
- **Missing translations** — update your locale pack from the community channel.
- **Startup crash** — check the log folder for a recent report and open an issue.

The support channel is available around the clock for anything the guide doesn’t cover.
